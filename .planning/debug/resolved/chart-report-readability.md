## Eliminated

- hypothesis: The -1 vs -3 mismatch is only a formatting bug in `build_band_snapshot`.
  reason: The same snapshot code reports different bands when fed different latest data dates; the stale monitor artifact explains the disagreement.

## Resolution

- root_cause: The chart used a fixed latest-date vertical line plus several endpoint annotations, causing unreadable stacking. Separately, report artifacts could be regenerated by the live monitor from stale/partial local data without a warning, so the visible chart could legitimately disagree with a later manual report summary.
- fix: Removed fixed latest-date vline and endpoint text annotations; darkened active and historical band fills; added report freshness metadata and visible HTML/JPEG stale-data warning; added `monitor.max_data_age_days`; skipped live alert evaluation when data is stale.
- verification: `./.venv/bin/python -m unittest discover -s tests` passed. `./.venv/bin/python main.py report` regenerated current artifacts with VOO data through 2026-05-07, current band -1, no `Today:` marker, and Data Status/Data Age fields.
