<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments -> bootstrap path | Operator-supplied config paths and output flags control what the runtime loads and displays |
| configured asset_prices path -> import system | Filesystem paths from config influence dynamic imports at runtime |
| redacted config -> stdout/json output | Display output can leak secrets or private recipients if not filtered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | T | `load_asset_prices_reader(...)` | mitigate | Import only `lib.read_utils.read_symbol_data` from the configured repo path and fail with an actionable error when the path is missing or unreadable |
| T-01-02-02 | I | `show-config` and `check --json` output | mitigate | Route all display output through `redact_service_config(...)` and include only the secret source label, never the credential values |
| T-01-02-03 | D | `run` preflight gate | mitigate | Block `main_loop(...)` and `send_test_email_now(...)` until preflight errors are empty; treat bad config and missing dependencies as startup failures, not loop-time warnings |
</threat_model>
