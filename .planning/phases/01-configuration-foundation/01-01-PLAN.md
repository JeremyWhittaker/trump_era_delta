<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed config -> runtime loader | Untrusted file contents from `config/service.json` and `config/service.local.json` cross into bootstrap logic |
| local secrets -> SMTP transport | `.env.local` or `~/.gmail_send/.env` credentials cross into Gmail delivery code |
| config display -> operator console | Redacted config output could leak secrets or private addresses if not filtered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-01 | T | `service_config.py` config merge | mitigate | Validate JSON shape explicitly, reject malformed files with actionable errors, and keep local overrides in a dedicated gitignored file |
| T-01-01-02 | I | `.env.local` / legacy Gmail env file | mitigate | Prefer `.env.local`, redact secrets in display output, and add `.gitignore` coverage for `.env.local` and local override files |
| T-01-01-03 | D | asset_prices path validation | mitigate | `validate_service_config(...)` must report missing repo/data paths before any runtime path starts work |
</threat_model>
